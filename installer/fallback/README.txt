XP Optimus Bypass - fallback install (no PowerShell)

Use this only if XP_Optimus_Bypass.bat cannot open the installer (for example on a PC where PowerShell is
restricted). It installs from the extracted folder itself, so keep the whole extracted folder.

1. Double-click install.bat and choose 1 (X-Plane only, recommended) or 2 (all Vulkan programs).
2. With 1, start X-Plane with start_xplane.bat in this folder.
3. The log is app\xp_optimus_bypass.log in the extracted folder.
4. To remove it, double-click uninstall.bat in this folder.

Do not use this and the normal installer at the same time: install.bat refuses if another installation
is registered.

---
備用安裝方式（不需要 PowerShell）

只有在 XP_Optimus_Bypass.bat 打不開安裝介面時才使用（例如 PowerShell 被限制的電腦）。
它直接從解壓縮的資料夾安裝，所以請保留整個資料夾。

1. 雙擊 install.bat，選 1（只給 X-Plane，建議）或 2（所有 Vulkan 程式）。
2. 選 1 的話，用這個資料夾裡的 start_xplane.bat 開 X-Plane。
3. log 在解壓縮資料夾的 app\xp_optimus_bypass.log。
4. 移除：雙擊這個資料夾裡的 uninstall.bat。

不要同時使用這個方式和一般安裝程式：如果已經有其他安裝，install.bat 會拒絕安裝。
